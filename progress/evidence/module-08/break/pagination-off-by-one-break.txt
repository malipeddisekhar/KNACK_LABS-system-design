1. INTENTIONAL BUG INJECTION
--------------------------------------------------------------------------------
File: api/src/links/links.service.ts (line 159)
Buggy Code:
    const offset = page * pageSize;

Correct Original Code:
    const offset = (page - 1) * pageSize;

Root Cause Analysis:
- The API query parameter `page` is 1-indexed (page 1 is the first page of results).
- PostgreSQL SQL `OFFSET` is 0-indexed (offset 0 skips 0 rows, starting at row 1).
- With `offset = page * pageSize`:
  * Page 1 computes: offset = 1 * 20 = 20.
    SQL: LIMIT 20 OFFSET 20.
    Effect: Skips the first 20 records entirely.
  * Page 2 computes: offset = 2 * 20 = 40.
    SQL: LIMIT 20 OFFSET 40.
    Effect: Skips the first 40 records.
  * Result: Records 1 through 20 are never returned by any valid page number.
  * Furthermore, if a user has fewer than 20 records in total (e.g. 5 records),
    page 1 returns 0 records (`items: []`) despite metadata stating `total: 5`.
